# OI-скринер (облако)

LIVE-скринер открытого интереса MOEX (AlgoPack). Один файл `oi_live.py`, только стандартная библиотека Python — зависимостей нет.

## Переменные окружения (задаются на хостинге, в код НЕ попадают)
- `ALGOPACK_TOKEN` — платный токен AlgoPack (обязательно в облаке).
- `ACCESS_KEY` — пароль-замок. Открывать так: `https://адрес/?key=ТВОЙ_ПАРОЛЬ` (ключ сохраняется в cookie).
- `PORT` — задаёт сам хостинг, трогать не нужно.

## Локально (Windows)
Токен берётся из `algopack_token.txt` рядом со скриптом. Двойной клик по `Скринер_LIVE.bat` или `python oi_live.py`.
